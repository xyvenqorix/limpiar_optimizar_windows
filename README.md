## 📖 Descripción

**Limpiador y Optimizador de Windows** es una herramienta creada para mejorar el rendimiento del sistema mediante limpieza, mantenimiento y optimización utilizando funciones internas de Windows.

Permite eliminar archivos innecesarios, limpiar historiales, realizar comprobaciones del sistema y ejecutar procesos de optimización de manera sencilla.

## ✨ Características

- 🧹 Limpieza rápida del sistema.
- 🗑️ Eliminación de archivos temporales.
- ⌨️ Limpieza del historial de Ejecutar (Win + R).
- 🧽 Limpieza profunda de Windows.
- 💽 Comprobación del disco.
- 🔧 Reparación de archivos del sistema.
- ⚡ Optimización automática.
- 🚀 Interfaz simple y rápida.

## ⚙️ Funciones disponibles

> [!TIP]
> Usa la opción **7** si quieres optimizar todo rápidamente.

### 1. Limpieza rápida
Elimina temporales, historial de Ejecutar (Win + R), archivos recientes y papelera.

### 2. Limpieza profunda
Incluye limpieza avanzada del sistema y caché de Windows Update.

### 3. Limpiar historial Ejecutar
Borra únicamente el historial del comando Win + R.

### 4. Limpiar archivos temporales
Elimina archivos basura acumulados.

### 5. Comprobación de disco
Analiza errores del disco mediante herramientas integradas de Windows.

### 6. Comprobación del sistema
Repara archivos dañados utilizando herramientas del sistema.

### 7. Ejecutar todo
Realiza una optimización completa automática (excepto SFC).

### 0. Salir
